## [2026 ARM Summer School](https://arm-development.github.io/arm-summer-school-2026/) Project 

Explainable XGBoost machine learning model for prediction of cloud condensation nucleai (at 10m) from other measurable aerosol quantities. 

## Project Scope

- Develop and train a ML model to obtain 10-m estimates of CCN from aerosol properties.
- Use explainable AI to test model understanding of physics
